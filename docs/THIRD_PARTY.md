# Third-party software and data notices

FIC source uses the repository MIT license. That license does not grant ownership
or redistribution rights over imported contacts, observations, addresses or reports.
The Python distribution carries its own copy of that same MIT license.

The release includes `SBOM.cdx.json`, `artifact-inventory.json` and
`THIRD_PARTY_NOTICES.txt`, generated by `tooling/release_inventory.py` from the actual
AGP **package/runtime** graph, cached Maven POM/artifact metadata, installed wheel
dependency metadata and PyInstaller native-input TOC. Compile-only and instrumentation
dependencies are not mislabeled as shipped runtime dependencies. The inventory does
not claim a complete source-level audit of every transitive/native implementation.
Unknown license metadata is reported explicitly, never guessed as Apache or MIT.

## Android

AndroidX, Kotlin, coroutines, Dagger/Hilt, OkHttp/Okio, Retrofit and other Maven
components retain their individual POM-declared licenses and packaged notices.
Most use Apache-2.0; the generated inventory is authoritative for the resolved
versions and exceptions. Packaging exclusions are not a license grant: the separate
release notices retain relevant upstream license/NOTICE material found in JAR/AARs.

Google Play services Location and related base/basement/tasks artifacts are **not
FIC MIT code**. Their actual POMs declare the Android Software Development Kit
License and link to Google's SDK terms. Do not label these proprietary components
Apache-2.0 or redistribute them as an independent SDK. FIC includes the existing
client libraries in its Android application; the Google Play services runtime on a
device is separately supplied by Google. Availability depends on a compatible device.

Official sources reviewed 2026-10-03:
- [Google Play services setup](https://developers.google.com/android/guides/setup)
- [Android SDK terms](https://developer.android.com/studio/terms)
- [Google APIs terms](https://developers.google.com/terms)

## Windows and Python

The Windows payload includes CPython, Tcl/Tk, the FIC wheel and its actual resolved
JSON Schema dependencies. Full upstream notices are bundled under `windows/notices`
and copied into the release notices. PyInstaller is the packaging tool; its bootloader
exception permits bundling applications under their own licenses. The generated
native-input list records actual DLL/PYD names/hashes, not a claim that each Windows
system DLL is open source. The portable EXE is unsigned.
The bundled CPython notice includes Microsoft's Distributable Code restrictions;
those runtime portions are not relicensed by FIC's MIT license. Preserve that notice
and its downstream-use/distribution conditions. The native inventory identifies the
actual VCRUNTIME DLLs included by the packager.

The wheel itself is pure Python (`py3-none-any`); its declared dependencies can have
separately tagged native wheels, including rpds-py. A platform-independent FIC wheel
tag does not assert every dependency is implemented in Python.

See the bundled CPython license for included OpenSSL and other component notices,
Tcl/Tk notices, and PyInstaller's full license/exception. SQLite is public domain.
Development UI automation dependencies are not imported into the workstation payload.

## External data/services

OpenStreetMap/Overpass and optional OpenCage data/provider attribution is separate
from software licensing. OpenCage requests require explicit per-address consent and
a user-supplied key, and remain governed by provider terms; no account/paid service
license is bundled. No contact dataset, address book, AI model or confidential API
key is included in FIC source or release assets.
