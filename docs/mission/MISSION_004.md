## Performance and remaining limits

The corrected emulator WebView reached DOM content loaded in 376 ms. Android reported 138,538 KiB of PSS for the FIC application process while the Earth panel was open. This excludes separately accounted WebView renderer processes. The desktop test reached DOM content loaded in 114 ms. These are single-run measurements on the engineering host. Thermal behavior, total handset memory, slow-network runtime and device-specific GPU compatibility still require physical testing.

Current coverage includes regional or archival sources. The panel identifies where each query operates. There is no worldwide live flight or AIS feed, global route solver, camera video verification, terrain height service or FIC MCP server.
